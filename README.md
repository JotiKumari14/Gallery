# 📸 Responsive Image Gallery

A responsive and visually appealing image gallery built with **HTML, CSS, and JavaScript**. The gallery showcases a collection of images arranged in a clean and modern grid layout.

## 🚀 Live Demo

🔗 https://jotikumari14.github.io/Gallery/index.html

## 📂 GitHub Repository

🔗 https://github.com/JotiKumari14/Gallery

## ✨ Features

- Responsive image gallery
- Modern and clean UI
- Hover effects
- Smooth layout
- Mobile-friendly design
- Fast loading using image links

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
